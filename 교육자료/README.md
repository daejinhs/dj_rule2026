## 발표용 뷰어

저장소 루트의 `slides/index.html`. 아트보드를 고친 뒤 다시 만들려면 저장소 루트에서:

```
node "교육자료/슬라이드/build-viewer.mjs" "교육자료/슬라이드" "slides/index.html"
```

조작 — `←` `→` `Space` 넘기기 / `Home` `End` / `O` 전체보기 / `F` 전체화면 / 화면 좌우 클릭.
덱은 하단 바에서 교직원·학생 전환. 순서는 각 슬라이드 바닥글 번호에서 읽으므로 캔버스 배치와 무관합니다.

**PDF가 필요하면 이 뷰어에서 Ctrl+P → PDF로 저장.** 브라우저 인쇄는 웹폰트를 그대로 넣기 때문에
캔버스의 PDF 내보내기와 달리 서체가 대체되지 않습니다. 용지는 13.333in × 7.5in 가로(16:9)로 잡혀 있습니다.

## 디자인 기준

- 신구대조표의 색 범례를 그대로 사용 — **빨강 = 변경·경고, 파랑 = 신설**
- 서체 Hahmlet(제목) + IBM Plex Sans KR(본문), Google Fonts
  → 캔버스의 PDF 내보내기는 서체가 대체됩니다. 발표용 뷰어의 Ctrl+P 를 쓰면 그대로 유지됩니다
- 슬라이드 규격 1280×720 (16:9)
